Пояснительная записка

FolderScan — приложение на Python с графическим интерфейсом PyQt6 для анализа дискового пространства. 
Программа сканирует выбранную папку, рекурсивно подсчитывает размеры вложенных каталогов, показывает даты изменения элементов и сортирует результаты по убыванию размера. 
Реализованы переходы между папками, фильтрация по размеру, поиск дубликатов и удаление файлов с подтверждением. 
Сканирование выполняется в отдельном потоке, чтобы интерфейс оставался доступным.

При разработке использовался Chat GPT 6.1 Sol и Claude Sonnet 5.5, для поиска информации о SQL запросах и модуле sqlite3.

Удачной считаю оптимизацию поиска дубликатов: сначала файлы группируются по размеру, затем для возможных совпадений вычисляется SHA-256. 
Содержимое читается блоками, поэтому файл не требуется целиком загружать в память. Для определения границ фильтра используется бинарный поиск.

Сверх технического задания я добавил сохранение и загрузку результатов через SQLite, SVG-логотип и игру.

Модули, которые не были запланированы: sqlite3 — работа с базой данных, pathlib — подготовка пути для открытия базы только для чтения, random — случайные ходы соперника, sys — запуск и завершение приложения. 
Компоненты QtGui и QtSvg понадобились для оформления и отображения логотипа. 

Не реализованы индикатор прогресса и отмена сканирования. Дубликаты ищутся только непосредственно в выбранной папке. Недоступные вложенные файлы пропускаются, поэтому размеры каталогов могут быть занижены.
