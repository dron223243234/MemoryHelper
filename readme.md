# FolderScan

Десктопное приложение на **Python + PyQt6**. Оно сканирует папку, показывает размеры файлов и вложенных каталогов, находит дубликаты и помогает удалить лишнее.

## Возможности

- **Сканирование папки** в отдельном потоке, интерфейс не зависает.
- **Таблица результатов**: имя, вес (КБ), дата изменения, номер группы дубликатов. Результаты отсортированы по убыванию размера.
- **Размеры папок** считаются рекурсивно. Недоступные элементы помечаются как `-1` и не входят в общую сумму.
- **Поиск дубликатов** среди файлов, лежащих прямо в сканируемой папке. Сначала файлы группируются по размеру, потом хешируются через SHA-256, поэтому проверка быстрее, чем полное хеширование.
- **Фильтр по размеру** (в КБ). Границы находятся бинарным поиском.
- **Навигация**: двойной клик по папке открывает её, кнопка «На уровень выше» поднимает на уровень вверх.
- **Удаление**:
  - выбранных файлов по номерам строк, например `1,3-5,8`;
  - всех повторов сразу: в каждой группе остаётся первый файл.
- **Сохранение и загрузка** результата в SQLite (`.db`). Загруженный результат открывается в режиме просмотра, удалять файлы из него нельзя.
- **Мини-игра «Крестики-нолики»** (кнопка «Занять себя»), на случай долгого сканирования.

## Установка

Нужен Python 3.10 или новее.

```bash
git clone <URL-репозитория>
cd FolderScan
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Нажмите **«Выбрать папку»** и дождитесь окончания сканирования.
2. Файлы из одной группы дубликатов помечены в столбце «Группа» как `Группа N`.
3. Чтобы отфильтровать по размеру, введите границы в КБ и нажмите **«Выбрать файлы по размеру»**. **«Сбросить фильтр»** возвращает полный список.
4. Чтобы удалить файлы, введите номера строк текущей таблицы (нумерация с 1) и нажмите **«Удалить файлы»**. Либо нажмите **«Удалить все повторы»**.
5. Результат можно сохранить кнопкой **«Сохранить результат в .db»** и позже открыть через **«Загрузить результат из .db»**.

## ⚠️ Важно

- Файлы удаляются **безвозвратно**, минуя корзину. Перед удалением показывается подтверждение со списком файлов.
- «Удалить все повторы» действует на **всю папку** независимо от фильтра.
- Дубликаты ищутся только среди файлов первого уровня выбранной папки, вложенные каталоги не проверяются.
- Размер папки может быть занижен, если часть вложенных файлов недоступна.
- Пока идёт сканирование, окно закрыть нельзя.

## Формат базы данных

Хранится один результат, при новом сохранении старый заменяется.

- `scan_info` — путь к папке, общий размер, дата изменения.
- `scan_files` — позиция, путь, размер, дата, номер группы дубликатов (`0` — нет группы).
